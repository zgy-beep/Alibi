## 5. rememberZoom（默认关闭）不得写入 lastZoomRatio

验证时应用数据为全新（files/datastore 不存在）：
  - 悬浮会话变焦前：run-as ls files/datastore -> No such file or directory
  - 点击 ＋ 到 1.25x、等待 >1s 后：仍为 No such file or directory
    => rememberZoom 默认 false 时悬浮变焦不写 DataStore（PASS）
证据：本记录的 §3 logcat、以及验收时的 adb 输出（见 verification-summary.md 复现命令）。

## 6. rememberZoom 开启 → 悬浮变焦写入 DataStore → 重启会话恢复

1) 打开应用 → 拍照 → 打开相机设置 → 打开“记住缩放倍率”开关：
   files/datastore/settings.json 变为
   {"photoCaptureSettings":{"rememberZoom":true},"hasSeenOnboarding":true,...}
2) HOME 后重新启动悬浮会话（rememberZoom=true），长按展开面板，点击 ＋ → 1.25x，
   等待 400ms debounce 后：
   {"photoCaptureSettings":{"rememberZoom":true,"lastZoomRatio":1.25},...}
   证据：verify-floating-remember-on-panel.png、verify-floating-remembered.png
3) 点击“停止”后重新启动会话：面板初始倍率显示 1.3×（恢复 lastZoomRatio=1.25）。
   证据：verify-floating-zoom-restored.png
   对应 logcat：PhotoCaptureService setZoomRatio 初始化路径 + 面板 1.3×。
=> rememberZoom 对悬浮模式 E2E 生效（PASS）。

  adb -s emulator-5580 install -r app/build/outputs/apk/debug/app-x86_64-debug.apk
并重新授权 CAMERA / POST_NOTIFICATIONS / SYSTEM_ALERT_WINDOW；
冷启动 MainActivity 正常（LaunchState COLD, 无 FATAL），随后 force-stop 保持干净状态。
