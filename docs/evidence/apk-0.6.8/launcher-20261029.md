# 华为真机桌面图标排查（2026-10-29）

设备：华为 Mate 70 Pro（PLR-AL50）。应用：`com.zgybeep.alibi`，`0.6.8 (25)`。

## 原因

当前空间为机主（User 0），应用仅安装在隐私空间（User 10）。检查时得到：

```text
am get-current-user: 0
User 0: installed=false hidden=false suspended=false enabled=0
User 10: installed=true hidden=false suspended=false enabled=0
query-activities --user 0: No activities found
```

因此机主桌面没有应用入口。源码的 MainActivity 已声明 MAIN/LAUNCHER、icon 和 roundIcon，各密度普通及圆形 PNG 图标资源均存在；本次没有修改应用代码或图标。

## 恢复与验证

将设备上已有的同一 APK 安装到机主空间：

```sh
adb shell cmd package install-existing --user 0 com.zgybeep.alibi
adb shell cmd package query-activities --user 0 \
  -a android.intent.action.MAIN -c android.intent.category.LAUNCHER \
  -p com.zgybeep.alibi
```

结果：

- `Package com.zgybeep.alibi installed for user: 0`。
- User 0 和 User 10 均为 `installed=true`；原隐私空间安装保持存在。
- 机主 Launcher 查询返回 `app.myzel394.alibi.MainActivity`，`enabled=true`、`exported=true`，图标 `icon=0x7f0d0000`。
- 华为桌面截图目视确认 Alibi 图标正常显示，UI 层级中图标归属 `com.huawei.android.launcher`。
- `am force-stop --user 0 com.zgybeep.alibi` 后点击桌面图标，成功冷启动；UI 层级中 `欢迎使用 Alibi!` 归属 `com.zgybeep.alibi`。重复检查通过，最后回到桌面。

桌面截图与原始 UI 层级包含个人桌面信息，仅保存在本机 `.tmp/launcher-check-20261029/`，不提交到仓库。

## 后续安装

通过 ADB 给机主安装时显式指定目标用户，并在安装后复查该用户的实际安装状态和 Launcher：

```sh
adb install --user 0 -r app/build/outputs/apk/release/app-arm64-v8a-release.apk
adb shell dumpsys package com.zgybeep.alibi
```
