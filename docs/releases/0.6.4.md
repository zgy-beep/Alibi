# Alibi 0.6.4

Alibi 0.6.4 adds optional vendor camera extensions, shows their support status in
the camera settings, and fixes quality-mode resolution on high-resolution
devices.

## Highlights

- **Optional camera extensions (night/HDR)**: the new “Camera extensions” setting
  is off by default. Auto prefers the vendor night extension, then HDR, and
  falls back to the standard pipeline when the device does not expose the
  extension or initialization fails (3 s timeout). Extension modes disable ZSL,
  forced frame rates, flash, and unsupported analysis streams.
- **Extension support status**: the camera settings now show whether the current
  lens exposes night/HDR extensions on the device, so unsupported devices are
  visible before taking a photo.
- **High-resolution quality fix**: the quality profile now queries the hardware
  JPEG maximum and only requests CameraX's software JPEG encoder when the
  hardware JPEG limit is 8 MP or lower. High-resolution devices keep the full
  sensor resolution instead of being capped to about 8 MP. On a Huawei Mate 70
  Pro, quality mode now captures 6144×8192 (50 MP, JPEG 100) instead of
  3264×2448 (8 MP).
- Extension support is vendor/device-dependent. Huawei devices use their own
  XMAGE pipeline instead of AndroidX CameraX extensions; the extension status
  reports “not available” and the app safely uses the standard pipeline.

## Compatibility

- Version: `0.6.4 (21)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.2/0.6.3` install in place (same release signing certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34; compile SDK: 36
- Universal APK (includes `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`)
- Huawei Mate 70 Pro tested on HarmonyOS 4.3 / Android 12: extensions
  unsupported (automatic fallback), quality mode 50 MP works. HarmonyOS NEXT
  cannot install Android APKs.

## Notes

- Night/HDR extensions require an OEM CameraX extension implementation. Supported
  devices include many Honor, Google Pixel, Samsung, Xiaomi, OPPO, vivo, and
  OnePlus models; Huawei does not expose these extensions to third-party APKs.
- 50 MP quality-mode photos are large (about 13–15 MB on the tested device) and
  slower to save; use the recommended mode for everyday photos.
- Extensions can reduce capture speed and may limit resolution depending on the
  vendor implementation.

The release APK is signed with the dedicated Alibi release certificate.
