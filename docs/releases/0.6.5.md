# Alibi 0.6.5

Alibi 0.6.5 brings a clean, modular settings architecture converging settings into
dedicated subpages (aligned with camera settings) and introduces a redesigned modern
About page.

## Highlights

- **Settings Convergence (Subpages)**:
  - Settings are now organized into clean, dedicated subpages instead of a single
    long and complex list with collapsible advanced switches.
  - **Audio settings**: duration, slice intervals, auto-delete, and encoding parameters
    (sampling rate, encoder, container format, bitrate, microphones) are now converged
    into `AudioSettingsScreen`.
  - **Video settings**: video quality, bitrate, frame rate, and retention duration
    now live in `VideoSettingsScreen`.
  - **Storage & backup**: save directory, filename timestamp formats, and settings
    import/export are converged into `StorageSettingsScreen`.
  - **Main Settings Hub**: the main settings screen now acts as an intuitive navigation
    center with high-level summaries for core capture modes, appearance, and security.
- **Redesigned About Page**:
  - Rebuilt with modern Material 3 styling and brand aesthetics.
  - Includes a quick-copy version badge for easier support feedback.
  - Highlights core privacy commitments: 100% offline, smart rolling loop retention,
    and discrete capture.
  - Links directly to the project GitHub repository and displays the GPL-3.0 license.
  - Removed obsolete upstream cryptocurrency donation addresses and GPG keys.

## Compatibility

- Version: `0.6.5 (22)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.1–0.6.4` install in place (same release signing certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34; compile SDK: 36
- Universal APK (includes `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`)

The release APK is signed with the dedicated Alibi release certificate.
