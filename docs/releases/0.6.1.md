# Alibi 0.6.1

Alibi 0.6.1 completes the independent application identity for this fork.

## Changes

- Android application ID changed from `app.myzel394.alibi` to
  `com.zgybeep.alibi`
- Debug application ID is `com.zgybeep.alibi.debug`
- Runtime photo service action names now derive from the current application ID
- Download links now point to GitHub Releases
- Version updated to `0.6.1 (18)`

## Compatibility

This is a new Android application identity. It can be installed alongside the
upstream Alibi package and does not share its app-private data.

## Package

- Application ID: `com.zgybeep.alibi`
- Version: `0.6.1 (18)`
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34
- Universal APK
