# Alibi 0.6.8

Alibi 0.6.8 adds an optional **standard camera mode**: a system-camera-like
screen with an always-visible viewfinder, tap-to-focus, pinch-to-zoom (also
while recording) and a normal shutter/record layout. The covert modes remain the
app default — the standard camera is an opt-in entry on the home screen.

## Highlights

- **Home entry**: a new “Standard camera” row below the recording cards opens the
  camera screen. It is intentionally secondary; audio, covert video and covert
  photo remain the primary paths.
- **Photo mode**:
  - Full-screen live viewfinder (preview is no longer hidden behind the black
    screen).
  - Tap anywhere on the viewfinder to focus and meter the exposure; a focus ring
    shows the AF/AE result (green = focused, red = failed).
  - Pinch-to-zoom with the same eased, coalesced camera-zoom pipeline as the
    covert photo mode; the ratio is shown as a chip.
  - Shutter button with a brief screen flash, shutter feedback from the existing
    haptic settings, and the configured grid overlay.
  - Flash quick toggle (off/auto/on), camera switch (only shown when the device
    exposes more than one camera), gallery shortcut, and a session that stops
    when the app leaves the foreground.
- **Video mode**:
  - Live viewfinder before recording (pinch to preselect the zoom ratio).
  - Recording starts from the same button; the recorder service then owns the
    viewfinder, so the picture stays visible while recording.
  - Pinch-to-zoom while recording, applied at camera level so the recorded file
    zooms as well; tap-to-focus, torch, pause/resume and a live timer.
  - Stop saves through the normal Alibi save pipeline (same folder, index and
    snackbar flow as the covert recorder).
- **Under the hood**:
  - `PhotoCaptureMode.STANDARD`, runtime camera rebuild for lens/flash switches
    (`reconfigure`), tap-to-focus support and published zoom bounds in
    `PhotoCaptureService`.
  - `VideoRecorderService` now binds a `Preview` use case together with the
    recording, supports detaching the viewfinder without stopping the recording,
    live smooth zoom and tap-to-focus.
  - The recorder save handler moved to the navigation host so saves triggered from
    the standard camera screen use exactly the same path as the covert screens.

## Compatibility

- Version: `0.6.8 (25)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.1–0.6.7` install in place (same release signing certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34; compile SDK: 36; CameraX 1.5.3
- Architecture split APKs (about 30 MB each):
  - `app-arm64-v8a-release.apk` (modern 64-bit devices)
  - `app-armeabi-v7a-release.apk` (32-bit devices)
  - `app-x86_64-release.apk` (64-bit emulators)
  - `app-x86-release.apk` (32-bit emulators)

## Known limits

- The standard camera screen is portrait-oriented; rotating the device while a
  session is open can recreate the screen (the default app is rotated freely, but
  the standard camera view itself is tuned for portrait use).
- Camera switching is hidden on single-camera devices. On devices where the
  requested lens cannot be opened, the session reports an error instead of
  silently switching.
- Tap-to-focus relies on the device exposing AF/AE metering; fixed-focus cameras
  report a failed focus ring.
- Video stabilization/quality settings still come from the video settings page;
  the standard camera reuses the configured quality, bitrate and frame rate.
- Device acceptance for this release was executed on the `Pixel9_API36` emulator
  (single virtual camera, no flash); real-phone focus feel, flash behavior,
  multi-camera switching and rotation behavior still need physical verification.

The release APK is signed with the dedicated Alibi release certificate.
