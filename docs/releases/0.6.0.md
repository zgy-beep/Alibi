# Alibi 0.6.0

> Superseded by 0.6.1. This build uses the upstream application ID
> `app.myzel394.alibi`; use 0.6.1 for the independent `com.zgybeep.alibi`
> package.

This release adds configurable photo capture from a black screen or floating
shutter.

## Highlights

- Black screen and floating shutter photo capture
- Camera settings for capture strategy, resolution, frame size, flash,
  stabilization, continuous autofocus, vibration, grid lines, preview behavior,
  zoom memory, and front camera mirroring
- Zero shutter lag, higher capture frame rate, optical stabilization, and
  continuous autofocus when supported by the device
- Successful-capture haptic feedback with short light and standard profiles
- Photo recovery, background storage, continuous capture queueing, and recent
  photo browsing
- Performance and Material 3 UI improvements

## Package

- Version: `0.6.0 (17)`
- Application ID: `app.myzel394.alibi`
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34
- Universal APK

The release APK is signed with a dedicated release certificate. Installations
signed by a different certificate cannot be updated in place and must be
uninstalled first.
