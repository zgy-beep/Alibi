# Alibi 0.6.2

Alibi 0.6.2 unifies the settings screen with the camera-settings design and
makes camera zoom more responsive, including a new zoom panel on the floating
shutter.

## Highlights

- Settings screen rebuilt on the same section, panel, and row components as the
  camera settings page: small top app bar, grouped panels, dividers, switches,
  value rows, and quick-pick chips
- Settings reorganized into Appearance, Recording, Notifications & security,
  Advanced, and About; the language row shows the current in-app language
- Camera settings and general settings now share the same row components, so
  the two pages stay visually consistent
- Pinch-to-zoom now uses a latest-wins request queue: at most one CameraX zoom
  request is in flight, intermediate targets are dropped, and the preview no
  longer falls behind the gesture
- Floating shutter long-press panel now has zoom controls: − / current zoom / +,
  a logarithmic slider, tap-to-reset, and disabled states at the camera limits
- Zoom controls expose accessibility actions and remember the last zoom for
  floating sessions when "Remember zoom" is enabled
- Newly localized Chinese strings for the settings and floating zoom UI

## Compatibility

- Version: `0.6.2 (19)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.1 (18)` can be installed in place (same release signing
  certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34
- Universal APK (includes `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`)

The release APK is signed with the dedicated Alibi release certificate.
Installations signed by a different certificate cannot be updated in place and
must be uninstalled first.
