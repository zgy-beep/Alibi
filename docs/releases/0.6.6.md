# Alibi 0.6.6

Alibi 0.6.6 fixes launcher icon visibility on OEM home launchers (such as Huawei
HarmonyOS UniHomeLauncher) and includes full density launcher round icon assets.

## Highlights

- **Launcher Icon Visibility Fix**:
  - Explicitly configured `android:icon="@mipmap/ic_launcher"` and
    `android:roundIcon="@mipmap/ic_launcher_round"` on `MainActivity` in
    `AndroidManifest.xml`.
  - Fixes an issue on OEM launchers where the main activity defaulted to `icon=0x0`
    in package activity queries, preventing the icon from appearing on the home screen.
  - Added full fallback `ic_launcher_round.png` assets across all mipmap density
    directories (hdpi, mdpi, xhdpi, xxhdpi, xxxhdpi).
  - Tested and verified on physical Huawei Mate 70 Pro (PLR-AL50, HarmonyOS 4.3).

## Compatibility

- Version: `0.6.6 (23)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.1–0.6.5` install in place (same release signing certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34; compile SDK: 36
- Architecture split APKs (about 30 MB each):
  - `app-arm64-v8a-release.apk` (modern 64-bit devices)
  - `app-armeabi-v7a-release.apk` (32-bit devices)
  - `app-x86_64-release.apk` (64-bit emulators)
  - `app-x86-release.apk` (32-bit emulators)

The release APK is signed with the dedicated Alibi release certificate.
