# Alibi 0.6.3

Alibi 0.6.3 improves still-photo quality: larger default stills and a
quality-first capture profile.

## Highlights

- Recommended photo resolution now targets about 12 MP (4000×3000) for 4:3 and
  about 8 MP (3840×2160) for 16:9 instead of roughly 2–3 MP
- Quality-first stills: largest supported frame, JPEG quality 100 through a
  software JPEG encoder, high-quality noise reduction and edge processing when
  the device supports them, and a stable non-ZSL capture pipeline
- Recommended capture keeps the fast zero-shutter-lag path; non-ZSL devices use
  JPEG quality 98 instead of the CameraX default 95
- CameraX updated from 1.3.4 to 1.5.3, which fixes still-capture session
  failures on Android 16 / API 36 and enables the quality-first pipeline
- No change to the unified settings UI, pinch-zoom/overlay zoom, background
  recording, or photo save locations

## Compatibility

- Version: `0.6.3 (20)`
- Application ID: `com.zgybeep.alibi`
- Updates from `0.6.2 (19)` can be installed in place (same release signing
  certificate)
- Minimum Android version: Android 7.0, API 24
- Target SDK: 34
- Universal APK (includes `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`)

## Notes

- The 12 MP / maximum-resolution gains need a physical device to observe; the
  API 36 emulator camera tops out at 1856×1392.
- Photos still use a single-frame CameraX pipeline: OEM camera apps can exceed
  it with multi-frame HDR, night mode, and AI processing.
- The quality profile is slower to capture than the recommended/fast path.

The release APK is signed with the dedicated Alibi release certificate.
Installations signed by a different certificate cannot be updated in place and
must be uninstalled first.
